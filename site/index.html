Get started

내 프로젝트에서 시작하세요.

준비된 Python으로 실행하고, 리포트의 판정과 종료 코드를 함께 읽습니다.

01

검사 환경 준비

프로젝트의 가상환경과 의존성,
pytest·Ruff 등 검증기를 준비합니다.

02

도구와 샘플 받기

설치 경로와 샘플 소스를 함께 안내합니다.
소스는 확인한 커밋(태그 public-2026-09-14)으로 받습니다.

03

실행하고 결과 읽기

설정·리포트는 검사 대상 밖에 둡니다.
실행 직후 종료 코드를 저장합니다.

설치 명령 · 확인한 커밋으로 고정
pip install "git+https://github.com/ddayhyun/claimtrail-public.git@184283b9a99ac6eab06b7ad7c541fc4d01892019"
이 커밋은 CI(Ubuntu Python 3.9·3.12, Windows 3.12)를 통과했습니다. pytest·Ruff 같은 검사 도구는 같은 가상환경에 따로 설치합니다. 새 가상환경에서 샘플까지 돌려 보는 절차는 시작 안내에 있습니다.
