# Claimtrail 소개 사이트 (검토용 사본)

정적 한 페이지. 계정·DB·검사 서버 없음. 아직 호스팅에 배포하지 않은 소개 페이지 소스다.

출처: 2026-09-11 로컬에서 구현하고 검토한 정적 페이지를 `site/` 에 둔다. `index.html` 과 샘플 원문은 검토 시점 그대로다.

| 파일 | 내용 |
|---|---|
| `site/index.html` | 제품 설명 · 실제 샘플 리포트 · 시작하기 · 지원 범위 · 피드백. CSS 인라인, JS 없음 |
| `site/sample/report.md`, `site/sample/report.json` | 2026-09-10 CI(Ubuntu, Python 3.12) 실행 원문. 가공하지 않음 |

기준 자료: 2026-09-11 시안 전달 자료(팔레트·문구)와 이 저장소의 `docs/getting-started.md`.
화면의 샘플 수치(pytest 5/5, lint 통과, format 1파일 실패, 벽시계 0.52s/0.03s/0.03s, Python 3.12.14, pytest 9.1.1, Ruff 0.16.6, 2026-09-10 07:43:08 UTC)는 `site/sample/report.md` 그대로다. "형식 오류를 의도적으로 포함한 샘플" 표시를 유지한다.

자리표시자(공개 전 확정): 설치 명령 `<INSTALL_COMMAND>`, 샘플 다운로드 · 준비 중, 피드백 남기기 · 준비 중. 외부 리소스는 Google Fonts 뿐이다(폰트 없으면 시스템 글꼴로 대체). `og:image` 메타는 두지 않았다 — 공개용 이미지가 확정되면 파일과 함께 추가한다(검토 지적 반영, 2026-09-11).

로컬 미리보기 (저장소 루트에서):

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

그 뒤 브라우저에서 `http://127.0.0.1:8765/` 를 연다. 샘플 원문 링크는 `/sample/report.md`, `/sample/report.json`.

확인 범위(로컬 구현 기준, 2026-09-11): 데스크톱(1280·1440 폭)과 모바일(375 폭) 전 구간 렌더링, 가로 넘침 없음, 링크 3개 응답 200, 개인 경로 없음. 브라우저는 Chromium 계열 하나다.
